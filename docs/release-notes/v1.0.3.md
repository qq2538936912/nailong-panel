# v1.0.3
<!-- release-title: 依赖管理支持扫描脚本缺失依赖并一键批量安装 -->

## 版本概览

`v1.0.3` 在依赖管理页新增「扫描缺失依赖」能力：自动遍历脚本目录，解析 `@depe`、`[depe:]`、`requirements.txt` 与 `package.json`，对比已安装/排队中的 pip、npm 包，确认后可批量提交安装。

## 新增

- **扫描缺失依赖 API**：`POST /api/v1/deps/scan-missing`，返回 Python / Node.js 缺失项、来源文件及本地模块引用。
- **依赖管理页入口**：Node.js / Python3 标签工具栏新增「扫描缺失依赖」按钮，扫描后弹窗确认并调用现有安装队列。
- **扫描规则**：跳过 `node_modules`、`__pycache__` 等目录；`./xxx.js` 等本地模块仅提示，不走 pip/npm。

## 升级说明

```bash
git pull
docker compose up -d --build --force-recreate
```

若使用 `.env`，请把 `PANEL_VERSION` 改为 `1.0.3`（或与 `server/handler/version.go` 一致的值）。
