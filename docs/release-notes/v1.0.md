## 版本概览

`v1.0` 是 [qq2538936912/nailong-panel](https://github.com/qq2538936912/nailong-panel) 在 GitHub 上的首个正式发版。面板代码与更新通道改到本仓库，Release 会附带各平台安装包。

## 变更

- **发版仓库切换到 GitHub**：安装包、Magisk 模块和更新日志从本仓库 Release 发布。
- **系统设置「访问 GitHub」**：打开本仓库的 Release 页。
- **系统设置「检查系统更新」**：改为请求本仓库的 latest Release。仓库还没有 Release 时会明确提示，不再报笼统的 GitHub API 异常。
