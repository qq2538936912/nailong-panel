# v1.0.2
<!-- release-title: 修复 Docker 本地构建仍显示 v2.2.18 并误判已是最新版 -->

## 版本概览

`v1.0.2` 修复本地 `docker compose build` 时版本号仍被写入旧默认值 `2.2.18` 的问题。面板会把 `2.2.18` 当成当前版本，与 GitHub 上的 `v1.0.x` Release 比较时误判为「已经是最新版」。

## 修复

- **Dockerfile 默认 VERSION**：`Dockerfile` / `Dockerfile.debian` 的 `ARG VERSION` 同步为 `1.0.2`，不再沿用上游遗留的 `2.2.18`。
- **Compose 构建传参**：`docker-compose.yml` / `docker-compose.debian.yml` 通过 `PANEL_VERSION` 把版本号传给镜像构建；`.env.example` 已给出示例值。

## 升级说明

改过源码后请重新构建并重建容器：

```bash
docker compose up -d --build --force-recreate
```

若使用 `.env`，请把 `PANEL_VERSION` 改为 `1.0.2`（或与 `server/handler/version.go` 一致的值）。
