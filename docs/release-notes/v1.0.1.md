# v1.0.1
<!-- release-title: Debian 版 Docker 可用 .env 固定 Compose 文件，不必每次加 -f -->

## 版本概览

`v1.0.1` 是一个小版本，主要改善 Debian 版 Docker 本地构建/部署时的命令体验。

## 变更

- **新增 `.env.example`**：复制为项目根目录下的 `.env` 并保留 `COMPOSE_FILE=docker-compose.debian.yml` 后，可直接执行 `docker compose up -d --build`，无需每次附加 `-f docker-compose.debian.yml`。
- **README 补充说明**：在 Debian 部署段落写明上述用法。
